# تحلیل‌گر GEO فارسی — persian-geo-analyzer

**آیا محتوای فارسی شما برای هوش مصنوعی خواناست؟** این ابزار به متن فارسی
نمره‌ی استنادپذیری (۰ تا ۱۰۰) می‌دهد و پیشنهادهای عملی فارسی برای بهتر
شدن ارائه می‌کند. بدون نیاز به نصب هیچ کتابخانه‌ای — فقط پایتون.

> English: [README.md](README.md)

## چرا؟

کسب‌وکارهای فارسی‌زبان دارند ترافیک را به جواب‌های هوش مصنوعی (ChatGPT،
Claude، Perplexity) می‌بازند، و همه‌ی ابزارهای GEO فقط انگلیسی‌اند —
حتی بهترین اسکورر متن‌باز نمی‌تواند یک صفحه‌ی فارسی را نمره بدهد.
این ابزار همان خلأ را پر می‌کند.

## نصب

```bash
git clone https://github.com/mohammad-abbasi-sh/persian-geo-analyzer
cd persian-geo-analyzer
# هیچ دیپندنسی لازم نیست — فقط پایتون ۳
```

## استفاده

```bash
# تحلیل متن
python3 src/fa_geo.py --text "سئو یعنی بهینه‌سازی سایت برای موتورهای جستجو…"

# تحلیل یک صفحه‌ی وب
python3 src/fa_geo.py --url "https://example.com/article"

# خروجی JSON
python3 src/fa_geo.py --file page.html --json
```

## نمره‌دهی (۱۰۰ نمره، ۵ بخش)

| بخش | سقف | چه چیزی نمره می‌گیرد |
|---|---|---|
| کیفیت بلوک جواب | ۳۰ | تعریف با «یعنی/عبارت است از/گفته می‌شود»، تیتر «؟»، «طبق تحقیقات…» |
| خودکفایی متن | ۲۵ | طول ۱۳۰–۱۷۰ کلمه، ضمیر کم، نام خاص |
| خوانایی ساختاری | ۲۰ | لیست (اول/دوم/…)، قدم‌های شماره‌دار، پاراگراف کوتاه |
| چگالی آماری | ۱۵ | ٪، تومان/ریال، میلیون/میلیارد، سال شمسی، منبع |
| سیگنال یکتایی | ۱۰ | «بررسی ما نشان داد»، مثال واقعی، مطالعه‌ی موردی |
